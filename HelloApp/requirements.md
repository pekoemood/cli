# 作るもの
名前入力⇨Hello表示

# 要件定義
## 目的
ユーザーが入力した名前を返す

## ユースケース
ユーザーは名前を入力する
アプリは挨拶文を表示する
アプリを終了する

## 入力仕様
入力：　名前（文字列）
受け付ける形式：　文字列のみ（空白は削除）

## 出力仕様
Hello <name>!の形式で出力
改行をつける

## エラー、例外仕様
名前が見入力の場合は、エラーメッセージを表示のうえ、もう一度入力させる。

## 終了条件
挨拶文を表示したら終了


# 処理フロー
1. 「名前を入力してくださいと表示
2. 入力を読み込み
3. 入力をトリム
4. 空なら「未入力です。もう一度」と表示して２に戻る
5. Hello <name>!と表示
6. 終了
